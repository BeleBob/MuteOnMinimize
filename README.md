# MuteOnMinimize

Дополнение для KDE Plasma 6: выбранные приложения замолкают, пока их окна свёрнуты
или закрыты другими окнами, и снова звучат, когда к ним вернулись.

*A KDE Plasma 6 add-on that mutes selected applications while their windows are minimized
or in the background. Available in English, Russian, Ukrainian and German.*

**Состояние:** первая рабочая версия, проверена на Plasma 6.7 (Wayland) с PipeWire 1.6.

## Как это работает

- Скрипт KWin следит за окнами. Приложение замолкает, когда свёрнуты **все** его окна.
- По умолчанию оно замолкает и тогда, когда на его экране впереди другое окно, например после Alt+Tab.
  С двумя мониторами звук остаётся, если вы ушли в окно на другом мониторе.
  Этот режим отключается галочкой в настройках.
- Звук плавно затухает за секунду, а возвращается сразу.
- Глушит небольшой пользовательский сервис `muteonminimized`. Он запускается сам, когда скрипт к нему обращается.
- Звук приложений, которые играют из дочерних процессов (Discord и другие на Electron), тоже глушится.
  Поддерживаются игры под Wine/Proton и приложения из Flatpak.
- Ваш собственный mute не трогается, а глушение не сохраняется: если закрыть приложение заглушённым,
  в следующий раз оно запустится со звуком.

Нужны KDE Plasma 6 и PipeWire (с pipewire-pulse или без).

## Установка

### Arch Linux и производные

Пакет в AUR пока не опубликован. Собрать его можно из репозитория:

```sh
git clone https://github.com/BeleBob/MuteOnMinimize.git
cd MuteOnMinimize/packaging/aur/muteonminimize-git
makepkg -si
```

### Из исходников

Нужны Rust (`cargo`), `clang`, `gettext` и заголовки PipeWire.

```sh
./install.sh               # в ~/.local, без root
./install.sh --uninstall   # удалить
```

Или для всей системы: `make && sudo make install`.

## Настройка

Включите скрипт: «Параметры системы» → «Диспетчер окон» → «Сценарии KWin» → **Тишина при сворачивании**.

Приложения можно выбрать тремя способами:

- **Меню окна**: Alt+F3 или правый клик по заголовку → «Глушить при сворачивании».
  У Firefox и других программ, которые рисуют заголовок сами, правый клик по заголовку открывает их собственное меню,
  поэтому для них используйте Alt+F3.
- **Сочетание клавиш** Meta+Ctrl+M для активного окна. Его можно сменить в «Параметрах системы» → «Комбинации клавиш» → KWin.
- **Страница настроек** скрипта (значок настроек рядом с ним): список через запятую.

В списке указывается класс окна (например, `firefox`, `discord`, `steam_app_287700`) или имя desktop-файла.
Класс окна можно узнать в «Параметрах системы» → «Особые параметры окон»: добавьте правило
и нажмите «Определить свойства окна».

Win+D в Plasma по умолчанию не сворачивает окна, а только прячет их («Взглянуть на рабочий стол»),
поэтому глушение по нему не срабатывает. Чтобы Win+D сворачивал окна, включите сценарий KWin
«Сворачивание всех окон» и назначьте его действию «Minimize all windows» сочетание Meta+D
вместо «Взглянуть на рабочий стол».

## Ограничения

- В микшере заглушённое приложение выглядит звучащим: используется отдельный от вашего mute механизм.
