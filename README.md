# MuteOnMinimize

Дополнение для KDE Plasma 6: выбранные приложения замолкают, пока их окна свёрнуты,
и снова звучат, когда окно развернули.

*A KDE Plasma 6 add-on that mutes selected applications while their windows are minimized.*

**Состояние:** в разработке, готовых сборок пока нет.
